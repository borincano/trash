# Descargar MUZZ GALAXY

## APK Android
- [MUZZ-GALAXY-debug.apk](./MUZZ-GALAXY-debug.apk) (~6 MB)
- [MUZZ-GALAXY-debug.zip](./MUZZ-GALAXY-debug.zip) (mismo archivo en ZIP)

**Clave del juego:** `2025`

### Instalar
1. Descarga el APK en tu Android
2. Permite instalar apps de orígenes desconocidos
3. Abre el archivo e instala
4. Al iniciar, usa la clave **2025**
